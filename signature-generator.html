Using this in Outlook: Outlook (Settings → Mail → Compose and reply → Signatures) uses Word's rendering engine, not a browser. "Copy signature" copies the rendered signature so you can paste it directly into that signature editor. If Outlook still reformats something after pasting, use "Download .html", open it in a browser, and copy from there instead — some Outlook builds handle a browser-sourced copy more reliably.
